Subtitle Checker - how to install and use (Windows)
====================================================

Needs: a 64-bit Windows 10 or 11 PC, internet, and the Sarvam API key (you get
it separately).

Install
1. Double-click Subtitle-Checker-Setup.exe.
2. If Windows says "Windows protected your PC", click "More info" then
   "Run anyway". The app is not signed yet, so Windows shows this once.
3. Click through the installer (tick "Create a desktop shortcut" if you want
   one). No admin password is needed. It opens the app at the end.

Use
1. Open Subtitle Checker from the Start menu (or the desktop shortcut).
   A page opens in your browser.
2. First time only: paste the Sarvam API key and click Save. The app checks
   the key with Sarvam. If it says the key was not accepted, check that you
   copied all of it. To use a different key later, click "Change API key"
   (top right).
3. Choose a video, pick the language, click "Run check". Keep the page open;
   the bar shows how far it has got.
4. When the check is done, click "Open report". Old reports stay under
   "Past checks" (reload the page to see the newest one there).
5. Click "Quit app" (top right) when you are finished.

Where things are: your reports are in the "Subtitle Checker" folder in your
user folder (C:\Users\<you>\Subtitle Checker). The page explains most problems in
plain words. If it says "Something went wrong", send the app.log file from that
folder.

Privacy: the video stays on your computer. Only small cropped subtitle images
and short audio clips are sent to Sarvam to read and listen.

Uninstall: Settings > Apps > Installed apps > Subtitle Checker > Uninstall.
Your reports in C:\Users\<you>\Subtitle Checker are kept.
